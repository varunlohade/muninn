# PayPal AI Hackathon — rules digest (read 2026-11-10)
Source: https://paypalaihackathon.devpost.com/ and /rules

## Deadline
- Submit by **Thu Nov 12, 2026, 12:00 pm PST**. No edits after that.
- Judging Dec 1-15. Winners ~Dec 21.
- 32,457 participants registered.

## Must have (Stage One = pass/fail)
- Meaningful use of a PayPal API/SDK (sandbox). Venmo, Braintree etc. count.
- Meaningful use of any AI tool/model.
- Working build: hosted demo URL, or full setup steps in the repo. Mockups fail.
- Public GitHub/GitLab/Bitbucket repo, open-source LICENSE visible in About.
- Text description + list of AI tools and how they are used.
- YouTube video, public, under 3 min, shows it running on its device. No copyrighted music.
- English. Test credentials/sandbox logins in README.
- Existing projects OK only if significantly updated after Oct 1; explain the update.

## Stage Two — 5 criteria, equal weight
1. Technological Implementation (first tie-breaker)
2. Design (complete product, not a PoC)
3. Potential Impact (real problem, real audience, shown in demo)
4. Innovation/Idea
5. Presentation (video end-to-end, problem/who/why)

## Prizes ($67.5k cash)
- Grand: $12k / $8k / $5k
- Honorable ($5k each): Most Creative, Most Impactful, Best Demo Delivery, Best Use of PayPal+AI, Best Use of Agentic Commerce
- Sponsor: AG Grid $5k/$2k/3x$1k; APIMatic 3x$1k; Bryntum 3x$1k; Channel3 $1.5k; Render credits
- Max per project: 1 Grand OR 1 Honorable, PLUS 1 Sponsor prize.
- Multiple submissions allowed if substantially different.

## PayPal's own idea list (resources page)
- Agents that transact, not just recommend; agent-to-agent payments.
- Money movement: pay by phone number, bill split from receipt photo, instant gig payouts.
- Business tools: multi-currency invoices, creator tips, marketplace split payments, POS add-on.
- Consumer: auto-budget PayPal txns, **"request money" inside a chat app**, simple checkout for niche groups.
- Social impact: accessible donations, microloans, community money pools.
- Tools: PayPal Agent Toolkit (github.com/paypal/AI-Toolkit, ~43 tools), remote MCP server mcp.paypal.com, REST APIs, JS SDK v6.
